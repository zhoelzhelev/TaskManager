# TaskManager

Simple app where people can manage their daily tasks. The app has improvements from my previous MAUI app. There is multiple pages and tasks models to add.

## Technologies Used

| Technology | Purpouse |
|---|---|
| C# | Main programing language |
| .NET MAUI | Main framework |
| XAML | Design of the app|

## Installation and Setup

### Prerequisites

- .NET 10 SDK
- Visaul studio 2022 or another compatible IDE
- An android smartphone or android emulator

### Steps

1. Copy the GitHub repository URL
2. Clone the repository
3. Opent the project in your IDE
4. Check the .NET MAUI workload Open Visual Studio
5. Restore NuGet packages
